# T08 — Reproducible Luna comparison and regression evidence

Builder: Composer Standard or Luna medium. Reviewer: Sol high. Depends on T02; use T03/T04 input contracts. Own evals files only. No routine production dual-generation.

Build a harness that saves complete candidate inputs, prompts/policy versions, model settings and outputs for replay. Existing archived briefings store selected outputs, so they alone cannot reconstruct a fair paired test. Include public/synthetic fixtures in the repo; keep private preferences/input snapshots out of public commits.

Prepare 20 edition-equivalent cases across news/sport/finance, English/French/Italian, quiet and busy periods, sparse feeds, preference edge cases and malicious instruction-like source text. Start with Haiku versus GPT-6 Luna reasoning none on identical preselection. Try Luna low only on a small subset where a measured quality issue warrants it. Then compare T07 selection separately. Do not change model, reasoning, prompt and ranking simultaneously and attribute the result to one factor.

Automate schema validity, source-ID membership, duplicate checks, length and explicit preference rules. Use blinded human/Sol review for unsupported claims, factual numbers, ranking usefulness, concision and diversity; mechanical citation validity is not factual support. Record failures, latency, input/output/cache/reasoning usage, retries and cost including judge costs separately.

Acceptance thresholds: all deterministic safety/schema invariants pass; zero critical unsupported claims in the acceptance sample; no material overall quality regression under a rubric fixed before outputs are reviewed; measured cost and latency report; limitations clearly stated. Report individual cases rather than relying only on a single model-generated score.

Prepare an explicit live evaluation cap and dry-run estimate. Twenty paired full editions project to about $0.58 in provider calls from the prior sample, before retries/reasoning/judging. Execute paid tests only under the implementation session's authorized budget. When keys or authorization are absent, deliver the runnable harness and mark live quality unverified. Provide a seven-day canary checklist and rollback criteria for T09.
